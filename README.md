# My Sports

Installable personal sports dashboard for:

- Tottenham Hotspur
- Bath Rugby

## App
This repository contains the live source for the My Sports Progressive Web App.

The intended GitHub Pages address is:

`https://atw0401.github.io/Sports/`

## Android installation
Once GitHub Pages is enabled, open the Pages address in Chrome on Android and choose **Install app** or **Add to Home screen**.
